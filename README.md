Palmera Bay is an original open-world crime game that plays entirely offline in a desktop browser. Explore a living city on foot and by car, with traffic and pedestrians, cars to steal, a wanted level and police chases, combat, six story missions, a HUD with a minimap, and a start screen with save support — all city, characters, vehicles, story, art, sound and music made from scratch, with nothing taken from Rockstar Games.

## Run it

```sh
node serve.ts
# then open http://localhost:8080 in a desktop browser
```
